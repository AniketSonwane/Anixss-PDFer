ABOUT & TECHNICAL SPECIFICATIONS

SECURITY & ARCHITECTURE

Anixss-PDFer is engineered specifically for security-conscious developers, professionals, and users who require complete document confidentiality.

100% Client-Side Processing

Anixss-PDFer operates entirely within your browser's sandboxed JavaScript and WebAssembly runtime. Documents you select are loaded directly into client RAM using standard web APIs (FileReader and ArrayBuffer).

Zero bytes of document content are transmitted across the network. No backend servers, cloud databases, serverless functions, or analytics scripts exist in this codebase.

Technology Stack

  • pdf-lib: Binary PDF parsing, merging, page extraction, geometry transformations, and lossless compilation.
  • PDF.js: Mozilla's browser rendering engine for vector-accurate canvas thumbnails and high-DPI rasterization.
  • JSZip: Pure JavaScript client-side compression for multi-image exports.
  • Tailwind CSS: High-contrast, monochromatic developer utility styling.

How to Verify Privacy

You can verify our privacy claims at any time:

  1. Open your browser Developer Tools (F12 or Ctrl+Shift+I).
  2. Switch to the Network tab.
  3. Perform any operation (Merge, Rotate, Remove, or Convert).
  4. Observe that zero POST requests or file upload payloads are dispatched.

Performance & Memory

Because processing relies on device memory, file size limits are governed only by available system RAM. Temporary Blob URLs generated during processing are automatically cleaned up to prevent memory leaks.

Works offline once downloaded or served on your local network.
